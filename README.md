# Barber Dori

## העלאה ל-GitHub (פעם אחת)

פתח **טרמינל**, הרץ:

```bash
cd barber-booking
bash דחוף-לgithub.sh
```

אם יבקש **Username** – הקלד: `eyalbash1-art`  
אם יבקש **Password** – הדבק **Personal Access Token** מ-GitHub (Settings → Developer settings → Personal access tokens), לא סיסמה.

אחרי שהדחיפה הצליחה – ב-Vercel: **Add New** → **Project** → בחר **batber-dori** → **Deploy**.  
הוסף Environment Variables: `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_ANON_KEY`.
